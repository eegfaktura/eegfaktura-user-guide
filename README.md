# eegFaktura — Benutzerhandbuch

End-user guide for **eegFaktura** (for EEG admins), published at
<https://eegfaktura.github.io/eegfaktura-user-guide/>. German, MkDocs Material, same style as the
eegFaktura member-onboarding user guide. Developer and architecture docs live in
[eegfaktura-docs](https://github.com/eegfaktura/eegfaktura-docs).

## Layout

| Path | Content |
|---|---|
| `docs/*.md` | chapters (numbered, in `nav` of `mkdocs.yml`) |
| `docs/images/` | screenshots, generated by `scripts/screenshots.py` — do not edit by hand |
| `docs/stylesheets/vfeeg.css` | palette (identical to the onboarding guide) |
| `docs/assets/fonts/` | Roboto / Roboto Mono, committed (no Google Fonts request), with licences |
| `scripts/screenshots.py` | Playwright script that logs in to a local eegFaktura stack and takes the screenshots |

## Preview and build

```bash
python -m venv .venv && . .venv/bin/activate
pip install --no-deps -r requirements-docs.txt
mkdocs serve            # http://localhost:8000
mkdocs build --strict   # what CI runs
```

## Screenshots

Screenshots are taken from a **local stack with fixture data only** — never from production or pilot, so no real
names, addresses or IBANs end up in the public guide. See `scripts/screenshots.py` for the stack, the login and how
to run it:

```bash
pip install --no-deps -r requirements-screenshots.txt
playwright install chromium
python scripts/screenshots.py
```

## Publishing

Every merge to `main` builds the site and pushes it to the `gh-pages` branch (`.github/workflows/docs.yml`).
Pull requests only scan (Trivy, OSV-Scanner) and build (`--strict`).

## Rules

- Versions are pinned (direct and transitive), at least 7 days old when pinned; new external sources only after
  asking. List: `EXTERNAL_SOURCES.md`.
- Every change gets an entry in `CHANGELOG.md`.
